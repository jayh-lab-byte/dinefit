# Dinefit

오늘 누구와, 어디서, 어떤 조건으로 먹을지 정하면 후보를 3곳으로 줄여 주는 식사 결정 앱입니다. 맛집 목록을 길게 보여 주지 않습니다.

카카오는 장소의 사실만 가져옵니다. 문장으로 적은 조건은 모델이 해석하고, 적합도 점수는 서버가 계산합니다. 주차, 메뉴 가격, 영업시간, 소음처럼 카카오 응답에 없는 항목은 확인된 사실로 쓰지 않습니다.

## 화면

1. 출발 위치, 동행, 인원, 예산, 반경, 음식을 고릅니다.
2. 정리된 조건을 확인한 뒤 검색합니다.
3. 조건에 맞는 3곳을 지도와 함께 보고, 한눈에 비교합니다.
4. 장소 상세에서 점수 근거와 피드백을 남깁니다.
5. 마음에 드는 곳은 보관합니다.
6. 통과한 장소가 없으면 반경이나 음식 조건을 풀어 다시 찾습니다.

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

| 변수 | 쓰임 |
| --- | --- |
| `OPENAI_API_KEY` | 조건 문장 해석과 추천 이유 |
| `OPENAI_MODEL` | 예: `gpt-4o-mini` |
| `KAKAO_REST_API_KEY` | 장소 검색, 지오코딩 |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | 지도 SDK |

카카오 콘솔에서 카카오맵 제품을 켜고, JavaScript 키의 사이트 도메인에 `http://localhost:3000` 을 넣습니다. 끝 슬래시는 붙이지 않습니다. REST 키의 호출 허용 IP는 비워 둡니다.

`.env.local` 은 Git에 올리지 않습니다. `NEXT_PUBLIC_` 값을 바꾼 뒤에는 개발 서버를 다시 시작합니다.

## 스크립트

```bash
npm run dev    # 개발 서버
npm run build  # 프로덕션 빌드
npm test       # 점수 계산 테스트
```
